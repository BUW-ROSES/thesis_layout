In the preparation of this thesis, I used the AI tools listed below.
AI was used as a support tool only and not as a substitute for understanding concepts and methods, for independent study, or for reading the scientific literature.
Before adopting any AI-generated content, I made sure that I can explain it, that I would recognize it if it were wrong, and that I verified its claims independently.

\minisec{ChatGPT (OpenAI, GPT-5)}
\begin{itemize}
    \item \textbf{Purpose:} Brainstorming and exploring the topic. I used it to get alternative explanations of concepts from \autoref{chap:background} that I did not understand from the literature at first, and to discuss possible research questions for \autoref{chap:intro}.
    \item \textbf{Extent:} Conversations only; no generated text was copied into the thesis.
    \item \textbf{Own work:} The research questions, the structure of the thesis, and all text bodies were formulated by me. I verified every explanation against the cited primary sources.
\end{itemize}

\minisec{Perplexity}
\begin{itemize}
    \item \textbf{Purpose:} Finding related work at the beginning of the thesis.
    \item \textbf{Extent:} Only used to obtain candidate papers.
    \item \textbf{Own work:} I read every paper cited in this thesis myself and checked all bibliographic data against the original publication. AI-generated summaries of papers were not used as a source.
\end{itemize}

\minisec{Grammarly}
\begin{itemize}
    \item \textbf{Purpose:} Proofreading spelling, grammar, and punctuation.
    \item \textbf{Extent:} Applied to all chapters. Suggestions were accepted or rejected individually; suggestions that would have changed the meaning of a sentence were rejected.
    \item \textbf{Own work:} Content and argumentation remain unchanged.
\end{itemize}

\minisec{DeepL Translator}
\begin{itemize}
    \item \textbf{Purpose:} Translating quotes from German sources into English.
    \item \textbf{Extent:} Three passages in \autoref{chap:background}, each marked as a translation in the text.
    \item \textbf{Own work:} I checked each translation against the German original and corrected technical terms.
\end{itemize}

\minisec{GitHub Copilot (VS Code extension)}
\begin{itemize}
    \item \textbf{Purpose:} Debugging and reviewing the code of the prototype described in \autoref{chap:impl}.
    \item \textbf{Extent:} Code completion for boilerplate code (argument parsing, logging) and explanations of compiler errors. All generated code snippets are marked by a comment in the source code.
    \item \textbf{Own work:} The concept, architecture, and core algorithms of the prototype were designed and implemented by me. I reviewed and tested all generated code. The evaluation in \autoref{chap:results} was carried out without AI assistance.
\end{itemize}
